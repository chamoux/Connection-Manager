# Game Mode (Phase 1) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a Windows tray app that detects when a Steam game is running and cuts background updaters (Google, Edge, Razer, Windows Update, Office, Adobe) off the internet until the game closes.

**Architecture:**

- One tray app that runs as admin. A logon task in Task Scheduler starts it with "highest privileges", so there is no UAC prompt.
- Every 2 seconds it lists the running processes and treats any exe inside a Steam library (or on the user's own list) as a game. It then decides whether Game Mode is on (Auto / On / Off plus a 2-minute grace period).
- While Game Mode is on, it keeps Windows Filtering Platform (WFP) block filters in step with the updater catalog.
- The filters live in a *dynamic* WFP session, so Windows deletes them when the app exits or crashes.

**Tech Stack:**

- C# / .NET 10 (`net10.0-windows`), WinForms tray icon.
- WFP through hand-written P/Invoke, checked against SDK 10.0.26100 headers.
- xUnit 2.9.3 and Microsoft.Extensions.TimeProvider.Testing 10.10.0.
- PowerShell 5.1 install scripts.

**Spec:** `docs/superpowers/specs/2026-10-08-connection-manager-design.md` (Phase 1 only; Data Saver is Phase 2).

```csharp
using System.Text;

namespace ConnectionManager.Core.Steam;

/// One node of Valve's KeyValues text format: a string value, or a block of named children.
public sealed class VdfNode
{
    private readonly List<KeyValuePair<string, VdfNode>> _children = [];

    private VdfNode(string? value) => Value = value;

    public string? Value { get; }
    public IReadOnlyList<KeyValuePair<string, VdfNode>> Children => _children;

    /// The first child with this key (Steam's keys are case-insensitive), or null.
    public VdfNode? this[string key] =>
        _children.FirstOrDefault(c => string.Equals(c.Key, key, StringComparison.OrdinalIgnoreCase)).Value;

    internal static VdfNode Leaf(string value) => new(value);
    internal static VdfNode Block() => new(null);
    internal void Add(string key, VdfNode child) => _children.Add(new(key, child));
}

/// Parses the KeyValues text files Steam writes, such as libraryfolders.vdf.
public static class Vdf
{
    private readonly record struct Token(string Text, bool Quoted)
    {
        public bool Is(char brace) => !Quoted && Text.Length == 1 && Text[0] == brace;
    }

    public static VdfNode Parse(string text)
    {
        var root = VdfNode.Block();
        var pos = 0;
        ParseBlock(text, ref pos, root, topLevel: true);
        return root;
    }

    private static void ParseBlock(string text, ref int pos, VdfNode block, bool topLevel)
    {
        while (NextToken(text, ref pos) is { } key)
        {
            if (key.Is('}'))
            {
                if (topLevel) throw new FormatException("Unexpected '}'");
                return;
            }
            if (key.Is('{')) throw new FormatException("A block needs a key before '{'");

            var value = NextToken(text, ref pos) ?? throw new FormatException($"Key '{key.Text}' has no value");
            if (value.Is('{'))
            {
                var child = VdfNode.Block();
                ParseBlock(text, ref pos, child, topLevel: false);
                block.Add(key.Text, child);
            }
            else if (value.Is('}')) throw new FormatException($"Key '{key.Text}' has no value");
            else block.Add(key.Text, VdfNode.Leaf(value.Text));
        }
        if (!topLevel) throw new FormatException("A block is missing its closing '}'");
    }

    private static Token? NextToken(string text, ref int pos)
    {
        while (pos < text.Length)
        {
            var c = text[pos];
            if (char.IsWhiteSpace(c))
            {
                pos++;
                continue;
            }
            if (c == '/' && pos + 1 < text.Length && text[pos + 1] == '/')
            {
                while (pos < text.Length && text[pos] != '\n') pos++;
                continue;
            }
            if (c is '{' or '}')
            {
                pos++;
                return new Token(c.ToString(), false);
            }
            return c == '"' ? ReadQuoted(text, ref pos) : ReadBare(text, ref pos);
        }
        return null;
    }

    private static Token ReadQuoted(string text, ref int pos)
    {
        var sb = new StringBuilder();
        pos++; // opening quote
        while (pos < text.Length)
        {
            var c = text[pos++];
            if (c == '"') return new Token(sb.ToString(), true);
            if (c == '\\' && pos < text.Length)
            {
                var escaped = text[pos++];
                sb.Append(escaped switch { 'n' => '\n', 't' => '\t', _ => escaped }); // \\ and \" keep the second character
                continue;
            }
            sb.Append(c);
        }
        throw new FormatException("A quoted string is missing its closing quote");
    }

    private static Token ReadBare(string text, ref int pos)
    {
        var start = pos;
        while (pos < text.Length && !char.IsWhiteSpace(text[pos]) && text[pos] is not ('{' or '}' or '"')) pos++;
        return new Token(text[start..pos], false);
    }
}
```

```csharp
using Microsoft.Win32;

namespace ConnectionManager.Core.Steam;

/// Finds the steamapps\common folders of every Steam library on this PC.
public static class SteamLibraries
{
    /// Steam's own folder from the registry, or null when Steam is not installed.
    public static string? ReadSteamPath()
    {
        using var user = Registry.CurrentUser.OpenSubKey(@"Software\Valve\Steam");
        if (user?.GetValue("SteamPath") is string path && path.Length > 0) return path;
        using var machine = Registry.LocalMachine.OpenSubKey(@"SOFTWARE\WOW6432Node\Valve\Steam");
        return machine?.GetValue("InstallPath") as string;
    }

    /// One steamapps\common folder per library, Steam's own folder first. `readFile` returns null for a missing file.
    public static IReadOnlyList<string> FindCommonFolders(string? steamPath, Func<string, string?> readFile)
    {
        if (string.IsNullOrWhiteSpace(steamPath)) return [];
        var steam = Normalize(steamPath);
        var roots = new List<string> { steam };
        foreach (var file in new[] { Path.Combine(steam, "steamapps", "libraryfolders.vdf"), Path.Combine(steam, "config", "libraryfolders.vdf") })
        {
            if (readFile(file) is not { } text) continue;
            try
            {
                roots.AddRange(ParseLibraryRoots(text).Select(Normalize));
            }
            catch (Exception ex) when (ex is FormatException or ArgumentException)
            {
                // A damaged file still leaves Steam's own library.
            }
            break;
        }
        return roots.Distinct(StringComparer.OrdinalIgnoreCase).Select(r => Path.Combine(r, "steamapps", "common")).ToList();
    }

    /// Library folders from libraryfolders.vdf, in both the old ("1" "D:\\Lib") and new ("1" { "path" ... }) layouts.
    public static IReadOnlyList<string> ParseLibraryRoots(string vdfText)
    {
        var folders = Vdf.Parse(vdfText)["libraryfolders"];
        if (folders is null) return [];
        var roots = new List<string>();
        foreach (var (key, node) in folders.Children)
        {
            if (node.Value is { } oldStyle && int.TryParse(key, out _)) roots.Add(oldStyle);
            else if (node["path"]?.Value is { } path) roots.Add(path);
        }
        return roots;
    }

    /// Steam writes its own path with forward slashes ("c:/program files (x86)/steam"). A drive root keeps its slash.
    public static string Normalize(string path)
    {
        var full = Path.GetFullPath(path.Replace('/', '\\'));
        return full.Length > 3 ? full.TrimEnd('\\') : full;
    }

    public static string? ReadFileOrNull(string path)
    {
        try
        {
            return File.Exists(path) ? File.ReadAllText(path) : null;
        }
        catch (Exception ex) when (ex is IOException or UnauthorizedAccessException)
        {
            return null;
        }
    }
}
```

```csharp
        if (_always.Contains(path)) return true;

        if (library is null) return false;

        if (folders.Any(f => ExcludedFolderNames.Contains(f, StringComparer.OrdinalIgnoreCase))) return false;
        var fileName = Path.GetFileName(path);
        return !ExcludedFileNameParts.Any(p => fileName.Contains(p, StringComparison.OrdinalIgnoreCase));
```

```csharp
namespace ConnectionManager.Core.Games;

/// Game state after the grace period: Active stays true until GraceEndsAt passes with no game running.
public sealed record GameState(bool Active, string? GameName, DateTimeOffset? GraceEndsAt)
{
    public static readonly GameState Idle = new(false, null, null);
}

/// Turns "which games are running right now" into a steady on/off state, so Game Mode doesn't flicker when a game restarts.
public sealed class GameSessionTracker
{
    private readonly TimeProvider _time;

    public GameSessionTracker(TimeProvider time, TimeSpan grace)
    {
        _time = time;
        Grace = grace;
    }

    public TimeSpan Grace { get; set; }
    public GameState State { get; private set; } = GameState.Idle;

    public GameState Update(IReadOnlyList<string> runningGamePaths)
    {
        var now = _time.GetUtcNow();
        if (runningGamePaths.Count > 0) return State = new GameState(true, Path.GetFileName(runningGamePaths[0]), null);
        if (!State.Active) return State;

        var graceEnds = State.GraceEndsAt ?? now + Grace;
        return State = now >= graceEnds ? GameState.Idle : State with { GraceEndsAt = graceEnds };
    }
}
```

```csharp
public static class NativeProcess

    private const uint ProcessQueryLimitedInformation = 0x1000;

    /// Full Win32 path of a running process, or null if it has exited or cannot be opened.
    public static string? GetPath(int pid)
    {
        var handle = OpenProcess(ProcessQueryLimitedInformation, false, pid);
        if (handle == IntPtr.Zero) return null;
        try
        {
            var buffer = new char[1024];
            var size = (uint)buffer.Length;
            if (!QueryFullProcessImageNameW(handle, 0, buffer, ref size)) return null;
            return ToLongPath(new string(buffer, 0, (int)size));
        }
        finally
        {
            CloseHandle(handle);
        }
    }

    /// Expands 8.3 short names (DOWNLO~1) so location checks, trust and blocks see the same path whichever way a
    /// process was found. Returns the path unchanged when it cannot be expanded (for example, the file is gone).
    public static string ToLongPath(string path)
    {
        var buffer = new char[1024];
        var length = GetLongPathNameW(path, buffer, (uint)buffer.Length);
        return length > 0 && length < buffer.Length ? new string(buffer, 0, (int)length) : path;
    }

    [DllImport("kernel32.dll", SetLastError = true)]
    private static extern IntPtr OpenProcess(uint access, bool inheritHandle, int processId);

    [DllImport("kernel32.dll", SetLastError = true, CharSet = CharSet.Unicode)]

    [DllImport("kernel32.dll", CharSet = CharSet.Unicode)]
```

```csharp
using System.Diagnostics;
using ConnectionManager.Core.Native;

namespace ConnectionManager.Core.Processes;

public sealed record RunningProcess(int Pid, string Path);

public interface IProcessSource
{
    /// Running processes whose program path could be read.
    IReadOnlyList<RunningProcess> GetRunning();
}

/// Lists running processes. Paths are cached per PID, so each new process is opened only once.
public sealed class SystemProcessSource : IProcessSource
{
    private readonly Func<IEnumerable<int>> _listPids;
    private readonly Func<int, string?> _pathOf;
    private Dictionary<int, string?> _cache = new();

    public SystemProcessSource() : this(ListPids, NativeProcess.GetPath) { }

    public SystemProcessSource(Func<IEnumerable<int>> listPids, Func<int, string?> pathOf)
    {
        _listPids = listPids;
        _pathOf = pathOf;
    }

    public IReadOnlyList<RunningProcess> GetRunning()
    {
        var next = new Dictionary<int, string?>();
        var running = new List<RunningProcess>();
        foreach (var pid in _listPids())
        {
            if (pid is 0 or 4) continue; // Idle and System have no program file
            if (!_cache.TryGetValue(pid, out var path)) path = _pathOf(pid);
            next[pid] = path;
            if (path is not null) running.Add(new RunningProcess(pid, path));
        }
        _cache = next; // exited PIDs drop out, so a reused PID is looked up again
        return running;
    }

    private static IEnumerable<int> ListPids()
    {
        var processes = Process.GetProcesses();
        try
        {
            return processes.Select(p => p.Id).ToArray();
        }
        finally
        {
            foreach (var p in processes) p.Dispose();
        }
    }
}
```

```csharp
using System.Text.Json;
using System.Text.Json.Serialization;

namespace ConnectionManager.Core.Settings;

/// Loads and saves settings.json. The installer locks the folder so only admins can write it.
public sealed class SettingsStore
{
    private static readonly JsonSerializerOptions Json = new(JsonSerializerDefaults.Web)
    {
        WriteIndented = true,
        RespectNullableAnnotations = false, // nulls are repaired below instead of rejecting the whole file
        Converters = { new JsonStringEnumConverter() },
    };

    private readonly string _path;

    public SettingsStore(string path) => _path = path;

    /// C:\ProgramData\ConnectionManager: settings.json and the logs folder.
    public static string DefaultFolder =>
        Path.Combine(Environment.GetFolderPath(Environment.SpecialFolder.CommonApplicationData), "ConnectionManager");

    /// A missing file gives defaults. A broken one is copied to settings.json.bad and defaults are used.
    public AppSettings Load()
    {
        if (!File.Exists(_path)) return new AppSettings();
        try
        {
            return Repair(JsonSerializer.Deserialize<AppSettings>(File.ReadAllText(_path), Json) ?? new AppSettings());
        }
        catch (JsonException)
        {
            File.Copy(_path, _path + ".bad", overwrite: true);
            return new AppSettings();
        }
    }

    /// Writes through a temp file, so a crash mid-write never leaves half a file.
    public void Save(AppSettings settings)
    {
        Directory.CreateDirectory(Path.GetDirectoryName(_path)!);
        var temp = _path + ".tmp";
        File.WriteAllText(temp, JsonSerializer.Serialize(settings, Json));
        File.Move(temp, _path, overwrite: true);
    }

    // A hand-edited file can hold nulls or silly numbers; fix them instead of failing later.
    private static AppSettings Repair(AppSettings s)
    {
        s.GraceMinutes = Math.Clamp(s.GraceMinutes, 0, 60);
        if (string.IsNullOrWhiteSpace(s.Hotkey)) s.Hotkey = AppSettings.DefaultHotkey;
        s.Catalog ??= new();
        s.ExtraBlocks ??= new();
        s.AlwaysGames ??= new();
        s.NeverGames ??= new();
        s.ExtraBlocks.RemoveAll(b => b is null || string.IsNullOrWhiteSpace(b.Path));
        s.AlwaysGames.RemoveAll(string.IsNullOrWhiteSpace);
        s.NeverGames.RemoveAll(string.IsNullOrWhiteSpace);
        return s;
    }
}
```

```csharp
namespace ConnectionManager.Core.Blocking;

/// Expands catalog paths: environment variables first, then * and ? wildcards in any folder or file part.
public static class PathPatterns
{
    private static readonly EnumerationOptions OneLevel = new() { MatchType = MatchType.Simple, IgnoreInaccessible = true };

    private static readonly EnumerationOptions Recursive = new()
    {
        MatchType = MatchType.Simple,
        IgnoreInaccessible = true,
        RecurseSubdirectories = true,
        AttributesToSkip = FileAttributes.ReparsePoint, // never follow junctions into loops
    };

    /// Existing files matching the pattern. A variable that isn't set on this PC matches nothing.
    public static IEnumerable<string> Expand(string pattern, Func<string, string>? expandEnv = null)
    {
        var expanded = (expandEnv ?? Environment.ExpandEnvironmentVariables)(pattern);
        if (expanded.Contains('%')) return [];
        var parts = expanded.Split('\\', StringSplitOptions.RemoveEmptyEntries);
        if (parts.Length < 2) return [];

        var current = new List<string> { parts[0] + '\\' }; // "C:\"
        for (var i = 1; i < parts.Length; i++)
        {
            var isFile = i == parts.Length - 1;
            var next = new List<string>();
            foreach (var dir in current.Where(Directory.Exists))
            {
                if (parts[i].Contains('*') || parts[i].Contains('?'))
                {
                    next.AddRange(isFile ? Safe(() => Directory.GetFiles(dir, parts[i], OneLevel)) : Safe(() => Directory.GetDirectories(dir, parts[i], OneLevel)));
                }
                else
                {
                    var candidate = Path.Combine(dir, parts[i]);
                    if (isFile ? File.Exists(candidate) : Directory.Exists(candidate)) next.Add(candidate);
                }
            }
            current = next;
        }
        return current;
    }

    /// Every .exe below a folder, at most `limit` of them.
    public static IReadOnlyList<string> ExesUnder(string folder, int limit, Func<string, string>? expandEnv = null)
    {
        var expanded = (expandEnv ?? Environment.ExpandEnvironmentVariables)(folder);
        if (expanded.Contains('%') || !Directory.Exists(expanded)) return [];
        return Safe(() => Directory.EnumerateFiles(expanded, "*.exe", Recursive).Take(limit).ToArray());
    }

    private static string[] Safe(Func<string[]> list)
    {
        try
        {
            return list();
        }
        catch (Exception ex) when (ex is IOException or UnauthorizedAccessException)
        {
            return [];
        }
    }
}
```

```csharp
using ConnectionManager.Core.Settings;

namespace ConnectionManager.Core.Blocking;

/// Turns enabled catalog entries and the user's own blocks into concrete targets, skipping anything protected.
public sealed class TargetResolver
{
    public const int FolderLimit = 400;

    private readonly Func<string, bool> _isProtected;
    private readonly Func<string, string>? _expandEnv;

    public TargetResolver(Func<string, bool> isProtected, Func<string, string>? expandEnv = null)
    {
        _isProtected = isProtected;
        _expandEnv = expandEnv;
    }

    public IReadOnlySet<BlockTarget> Resolve(IEnumerable<CatalogEntry> entries, IEnumerable<UserBlock> userBlocks)
    {
        var targets = new HashSet<BlockTarget>();
        foreach (var entry in entries)
        {
            foreach (var pattern in entry.Paths)
                foreach (var path in PathPatterns.Expand(pattern, _expandEnv)) AddApp(targets, path, entry.Name);
            foreach (var folder in entry.Folders)
                foreach (var path in PathPatterns.ExesUnder(folder, FolderLimit, _expandEnv)) AddApp(targets, path, entry.Name);
            foreach (var service in entry.Services) targets.Add(new BlockTarget(TargetKind.Service, service, entry.Name));
        }
        foreach (var block in userBlocks)
        {
            if (block.IsFolder)
                foreach (var path in PathPatterns.ExesUnder(block.Path, FolderLimit, _expandEnv)) AddApp(targets, path, "your list");
            else if (File.Exists(block.Path)) AddApp(targets, block.Path, "your list");
        }
        return targets;
    }

    private void AddApp(HashSet<BlockTarget> targets, string path, string label)
    {
        var full = Path.GetFullPath(path);
        if (!_isProtected(full)) targets.Add(new BlockTarget(TargetKind.App, full, label));
    }
}
```

```csharp
            try
            {
```

```csharp
using System.Security.Principal;
using ConnectionManager.Core.Blocking;

namespace ConnectionManager.Core.Wfp;

public sealed record ReconcileResult(int Added, int Removed, IReadOnlyList<(BlockTarget Target, string Message)> Failures);

/// Keeps the engine's filters equal to the wanted set of targets, touching only what changed.
public sealed class FilterReconciler
{
    private readonly IWfpEngine _engine;
    private readonly Dictionary<BlockTarget, IReadOnlyList<ulong>> _active = new();

    public FilterReconciler(IWfpEngine engine) => _engine = engine;

    public IReadOnlyCollection<BlockTarget> Active => _active.Keys;

    public ReconcileResult Apply(IReadOnlySet<BlockTarget> wanted)
    {
        var before = new Dictionary<BlockTarget, IReadOnlyList<ulong>>(_active);
        var failures = new List<(BlockTarget, string)>();
        int added = 0, removed = 0;
        try
        {
            _engine.InTransaction(() =>
            {
                foreach (var target in _active.Keys.Where(t => !wanted.Contains(t)).ToList())
                {
                    foreach (var id in _active[target]) _engine.DeleteFilter(id);
                    _active.Remove(target);
                    removed++;
                }
                foreach (var target in wanted.Where(t => !_active.ContainsKey(t)))
                {
                    try
                    {
                        _active[target] = _engine.AddBlock(target);
                        added++;
                    }
                    catch (Exception ex) when (ex is WfpException or IdentityNotMappedException)
                    {
                        failures.Add((target, ex.Message)); // e.g. the file vanished; the rest still apply
                    }
                }
            });
        }
        catch
        {
            // The transaction was rolled back, so the engine still holds the old filters.
            _active.Clear();
            foreach (var (target, ids) in before) _active[target] = ids;
            throw;
        }
        return new ReconcileResult(added, removed, failures);
    }

    public ReconcileResult Clear() => Apply(new HashSet<BlockTarget>());
}
```

```csharp
internal sealed class CurlCopy : IDisposable
{
    // HTTPS on purpose: an antivirus may route plain HTTP through a local proxy, which a block would not stop.
    // (msftconnecttest.com is no good here: its HTTPS certificate is for another host name, so curl exits 60.)
    public const string InternetUrl = "https://www.microsoft.com/";

    private readonly string _dir = Directory.CreateTempSubdirectory("cm-curl-").FullName;

    public CurlCopy()
    {
        ExePath = Path.Combine(_dir, "cm test curl.exe");
        File.Copy(Path.Combine(Environment.SystemDirectory, "curl.exe"), ExePath);
    }

    public string ExePath { get; }

    /// curl's exit code: 0 = fetched, 7 = could not connect (what a WFP block looks like), 28 = timed out.
    public int Fetch(string url = InternetUrl)
    {
        var start = new ProcessStartInfo(ExePath) { UseShellExecute = false, CreateNoWindow = true };
        foreach (var arg in new[] { "-s", "-o", "NUL", "--max-time", "10", url }) start.ArgumentList.Add(arg);
        using var process = Process.Start(start)!;
        process.WaitForExit(20_000);
        return process.HasExited ? process.ExitCode : -1;
    }

    /// Retries for a while: the engine may need a moment to drop a dead session's filters.
    public bool FetchesWithin(TimeSpan timeout)
    {
        var until = DateTime.UtcNow + timeout;
        while (true)
        {
            if (Fetch() == 0) return true;
            if (DateTime.UtcNow > until) return false;
            Thread.Sleep(1000);
        }
    }

    public void Dispose()
    {
        try
        {
            Directory.Delete(_dir, recursive: true);
        }
        catch (Exception ex) when (ex is IOException or UnauthorizedAccessException)
        {
            // A curl process still exiting can hold the file for a moment; the temp folder is cleaned later.
        }
    }
}
```

```csharp
        {

            {
                return;
            }
            catch (Exception ex) when (ex is SocketException or IOException)
            {
                // One broken client doesn't stop the server.
            }
        }
    }

    public void Dispose()
    {
        _stop.Cancel();
        _listener.Stop();
    }
```

```csharp
using System.Security.AccessControl;
using System.Security.Principal;

namespace ConnectionManager.Core.Wfp;

/// One filter condition plus the unmanaged memory it points to. Dispose after the filters are added (WFP copies the data).
internal sealed class FilterCondition : IDisposable
{
    private IntPtr _wfpBlob;    // from FwpmGetAppIdFromFileName0, freed with FwpmFreeMemory0
    private IntPtr _blobStruct; // our own FWP_BYTE_BLOB
    private IntPtr _bytes;      // our own security-descriptor bytes

    public FWPM_FILTER_CONDITION0 Value { get; private set; }

    /// Matches connections made by one program file.
    public static FilterCondition ForApp(string path)
    {
        WfpEngine.Check("FwpmGetAppIdFromFileName0", WfpNative.FwpmGetAppIdFromFileName0(path, out var blob));
        return new FilterCondition
        {
            _wfpBlob = blob,
            Value = new FWPM_FILTER_CONDITION0
            {
                fieldKey = WfpNative.ConditionAleAppId,
                matchType = WfpNative.MatchEqual,
                conditionValue = new FWP_CONDITION_VALUE0 { type = WfpNative.DataByteBlob, pointer = blob },
            },
        };
    }

    /// Matches connections made by a Windows service, through its per-service SID (NT SERVICE\name).
    public static FilterCondition ForService(string serviceName) =>
        ForSid((SecurityIdentifier)new NTAccount("NT SERVICE", serviceName).Translate(typeof(SecurityIdentifier)));

    /// The engine runs an access check of the connecting process's token against this descriptor. CC is the
    /// FWP_ACTRL_MATCH_FILTER right, so the filter matches processes whose token holds the SID.
    /// AccessCheck needs an owner and a group, hence O:SY G:SY.
    public static FilterCondition ForSid(SecurityIdentifier sid)
    {
        var descriptor = new RawSecurityDescriptor($"O:SYG:SYD:(A;;CC;;;{sid.Value})");
        var bytes = new byte[descriptor.BinaryLength];
        descriptor.GetBinaryForm(bytes, 0);

        var condition = new FilterCondition
        {
            _bytes = Marshal.AllocHGlobal(bytes.Length),
            _blobStruct = Marshal.AllocHGlobal(Marshal.SizeOf<FWP_BYTE_BLOB>()),
        };
        Marshal.Copy(bytes, 0, condition._bytes, bytes.Length);
        Marshal.StructureToPtr(new FWP_BYTE_BLOB { size = (uint)bytes.Length, data = condition._bytes }, condition._blobStruct, false);
        condition.Value = new FWPM_FILTER_CONDITION0
        {
            fieldKey = WfpNative.ConditionAleUserId,
            matchType = WfpNative.MatchEqual,
            conditionValue = new FWP_CONDITION_VALUE0 { type = WfpNative.DataSecurityDescriptor, pointer = condition._blobStruct },
        };
        return condition;
    }

    public void Dispose()
    {
        if (_wfpBlob != IntPtr.Zero) WfpNative.FwpmFreeMemory0(ref _wfpBlob);
        if (_blobStruct != IntPtr.Zero) Marshal.FreeHGlobal(_blobStruct);
        if (_bytes != IntPtr.Zero) Marshal.FreeHGlobal(_bytes);
        _blobStruct = IntPtr.Zero;
        _bytes = IntPtr.Zero;
    }
}
```

```csharp
using System.Runtime.InteropServices;
using ConnectionManager.Core.Blocking;

namespace ConnectionManager.Core.Wfp;

/// Owns one dynamic WFP session. Its filters live only as long as this object and this process: Windows deletes
/// them when the session closes, including when the process crashes. Needs admin rights.
public sealed class WfpEngine : IWfpEngine
{
    private const ushort SubLayerWeight = 0x4000;
    private const byte BlockWeight = 10;
    private const byte LoopbackPermitWeight = 15; // beats our blocks inside our sublayer

    // Outgoing connections and accepted incoming ones, IPv4 and IPv6.
    private static readonly Guid[] Layers =
    [
        WfpNative.LayerAleAuthConnectV4, WfpNative.LayerAleAuthConnectV6,
        WfpNative.LayerAleAuthRecvAcceptV4, WfpNative.LayerAleAuthRecvAcceptV6,
    ];

    private readonly Guid _subLayerKey = Guid.NewGuid(); // fresh per session, so two sessions never collide
    private IntPtr _handle;

    public WfpEngine(string sessionName = "Connection Manager")
    {
        if (!Environment.Is64BitProcess) throw new PlatformNotSupportedException("The WFP structures are laid out for 64-bit processes");

        var name = Marshal.StringToHGlobalUni(sessionName);
        try
        {
            // A 3 s transaction wait: 0 would mean the 15 s default, on the UI thread.
            var session = new FWPM_SESSION0 { displayData = new FWPM_DISPLAY_DATA0 { name = name }, flags = WfpNative.SessionFlagDynamic, txnWaitTimeoutInMSec = 3000 };
            Check("FwpmEngineOpen0", WfpNative.FwpmEngineOpen0(null, WfpNative.RpcCAuthnWinNt, IntPtr.Zero, ref session, out _handle));
        }
        finally
        {
            Marshal.FreeHGlobal(name);
        }

        try
        {
            InTransaction(() =>
            {
                AddSubLayer(sessionName);
                // Local traffic (127.0.0.1, ::1) always passes, so blocked apps keep talking to their own helpers.
                foreach (var layer in Layers) AddLoopbackPermit(layer);
            });
        }
        catch
        {
            Dispose();
            throw;
        }
    }

    public IReadOnlyList<ulong> AddBlock(BlockTarget target)
    {
        using var condition = target.Kind == TargetKind.App ? FilterCondition.ForApp(target.Value) : FilterCondition.ForService(target.Value);
        var ids = new List<ulong>(Layers.Length);
        try
        {
            foreach (var layer in Layers)
                ids.Add(AddFilter(layer, $"Connection Manager: block {target.Label}", WfpNative.ActionBlock, BlockWeight, condition.Value));
            return ids;
        }
        catch (Exception first)
        {
            // Never leave half a target blocked: nothing would remember to remove it. If the undo itself fails,
            // throw something the reconciler doesn't swallow, so the whole transaction is rolled back instead.
            foreach (var id in ids)
            {
                var code = WfpNative.FwpmFilterDeleteById0(_handle, id);
                if (code != 0 && code != WfpNative.ErrorFilterNotFound)
                    throw new InvalidOperationException($"Could not undo a half-added block for {target.Value}", first);
            }
            throw;
        }
    }

    public void DeleteFilter(ulong filterId)
    {
        var code = WfpNative.FwpmFilterDeleteById0(_handle, filterId);
        if (code != WfpNative.ErrorFilterNotFound) Check("FwpmFilterDeleteById0", code);
    }

    public void InTransaction(Action work)
    {
        Check("FwpmTransactionBegin0", WfpNative.FwpmTransactionBegin0(_handle, 0));
        try
        {
            work();
        }
        catch
        {
            WfpNative.FwpmTransactionAbort0(_handle);
            throw;
        }
        var commit = WfpNative.FwpmTransactionCommit0(_handle);
        if (commit == 0) return;
        WfpNative.FwpmTransactionAbort0(_handle); // never leave a transaction open: every later begin would fail
        throw new WfpException("FwpmTransactionCommit0", commit);
    }

    public void Dispose()
    {
        if (_handle == IntPtr.Zero) return;
        WfpNative.FwpmEngineClose0(_handle); // ends the dynamic session: every filter it added is deleted
        _handle = IntPtr.Zero;
    }

    internal static void Check(string operation, uint code)
    {
        if (code != 0) throw new WfpException(operation, code);
    }

    private void AddSubLayer(string name)
    {
        var display = Marshal.StringToHGlobalUni(name);
        try
        {
            var subLayer = new FWPM_SUBLAYER0 { subLayerKey = _subLayerKey, displayData = new FWPM_DISPLAY_DATA0 { name = display }, weight = SubLayerWeight };
            Check("FwpmSubLayerAdd0", WfpNative.FwpmSubLayerAdd0(_handle, ref subLayer, IntPtr.Zero));
        }
        finally
        {
            Marshal.FreeHGlobal(display);
        }
    }

    private void AddLoopbackPermit(Guid layer)
    {
        var loopback = new FWPM_FILTER_CONDITION0
        {
            fieldKey = WfpNative.ConditionFlags,
            matchType = WfpNative.MatchFlagsAllSet,
            conditionValue = new FWP_CONDITION_VALUE0 { type = WfpNative.DataUint32, uint32 = WfpNative.ConditionFlagIsLoopback },
        };
        AddFilter(layer, "Connection Manager: allow loopback", WfpNative.ActionPermit, LoopbackPermitWeight, loopback);
    }

    private ulong AddFilter(Guid layer, string name, uint action, byte weight, FWPM_FILTER_CONDITION0 condition)
    {
        var display = Marshal.StringToHGlobalUni(name);
        var conditionPtr = Marshal.AllocHGlobal(Marshal.SizeOf<FWPM_FILTER_CONDITION0>());
        try
        {
            Marshal.StructureToPtr(condition, conditionPtr, false);
            var filter = new FWPM_FILTER0
            {
                displayData = new FWPM_DISPLAY_DATA0 { name = display },
                layerKey = layer,
                subLayerKey = _subLayerKey,
                weight = new FWP_VALUE0 { type = WfpNative.DataUint8, uint8 = weight },
                numFilterConditions = 1,
                filterCondition = conditionPtr,
                action = new FWPM_ACTION0 { type = action },
            };
            Check("FwpmFilterAdd0", WfpNative.FwpmFilterAdd0(_handle, ref filter, IntPtr.Zero, out var id));
            return id;
        }
        finally
        {
            Marshal.FreeHGlobal(conditionPtr);
            Marshal.FreeHGlobal(display);
        }
    }
}
```

```csharp
        if (target.Kind == TargetKind.Service && MissingServices.Contains(target.Value)) throw new IdentityNotMappedException("not installed");

            foreach (var (id, target) in before) Filters[id] = target;

        }
```

```csharp
using ConnectionManager.Core.Blocking;
using ConnectionManager.Core.Games;
using ConnectionManager.Core.Logging;
using ConnectionManager.Core.Modes;
using ConnectionManager.Core.Processes;
using ConnectionManager.Core.Settings;
using ConnectionManager.Core.Steam;
using ConnectionManager.Core.Wfp;

namespace ConnectionManager.Core;

/// What the tray shows after each tick.
public sealed record ControllerStatus(
    bool Active, GameModeSetting Setting, GameState Game, int BlockedCount, IReadOnlyList<string> RunningGames, string? Error)
{
    public static readonly ControllerStatus Starting = new(false, GameModeSetting.Auto, GameState.Idle, 0, [], null);
}

/// The Game Mode loop. Each tick finds running games, decides whether Game Mode is on, and keeps the WFP filters in step.
/// Not thread-safe: the tray calls everything from its UI thread.
public sealed class GameModeController : IDisposable
{
    public static readonly TimeSpan RefreshWhileActive = TimeSpan.FromSeconds(60);
    public static readonly TimeSpan LibraryRefresh = TimeSpan.FromMinutes(5);

    private readonly IProcessSource _processes;
    private readonly IWfpEngine _engine;
    private readonly FilterReconciler _reconciler;
    private readonly TimeProvider _time;
    private readonly ILog _log;
    private readonly Func<string?> _steamPath;
    private readonly Func<string, string?> _readFile;
    private readonly string _appFolder;
    private readonly Func<string, string>? _expandEnv;
    private readonly GameSessionTracker _tracker;
    private readonly HashSet<string> _loggedFailures = new(StringComparer.OrdinalIgnoreCase);

    private AppSettings _settings = new();
    private string? _steam;
    private IReadOnlyList<string> _libraries = [];
    private GameClassifier _classifier = new([], [], []);
    private DateTimeOffset _librariesReadAt = DateTimeOffset.MinValue;
    private DateTimeOffset _resolvedAt = DateTimeOffset.MinValue;
    private DateTimeOffset _retryAt = DateTimeOffset.MinValue;
    private string? _lastError;
    private bool _active;

    public GameModeController(IProcessSource processes, IWfpEngine engine, TimeProvider time, ILog log,
        Func<string?> steamPath, Func<string, string?> readFile, string appFolder, Func<string, string>? expandEnv = null)
    {
        _processes = processes;
        _engine = engine;
        _reconciler = new FilterReconciler(engine);
        _time = time;
        _log = log;
        _steamPath = steamPath;
        _readFile = readFile;
        _appFolder = appFolder;
        _expandEnv = expandEnv;
        _tracker = new GameSessionTracker(time, TimeSpan.FromMinutes(_settings.GraceMinutes));
    }

    public ControllerStatus Status { get; private set; } = ControllerStatus.Starting;

    /// Call after every settings change. Blocks are recomputed on the next tick.
    public void ApplySettings(AppSettings settings)
    {
        _settings = settings;
        _tracker.Grace = TimeSpan.FromMinutes(settings.GraceMinutes);
        _classifier = new GameClassifier(_libraries, settings.AlwaysGames, settings.NeverGames);
        _resolvedAt = DateTimeOffset.MinValue;
        _retryAt = DateTimeOffset.MinValue; // a settings change deserves an immediate attempt
    }

    public ControllerStatus Tick()
    {
        var now = _time.GetUtcNow();
        if (now - _librariesReadAt >= LibraryRefresh) ReadLibraries(now);

        var games = _processes.GetRunning()
            .Select(p => p.Path)
            .Where(_classifier.IsGame)
            .Distinct(StringComparer.OrdinalIgnoreCase)
            .ToList();
        var game = _tracker.Update(games);
        var active = ModeLogic.IsGameModeActive(_settings.Mode, game);

        var due = active ? !_active || now - _resolvedAt >= RefreshWhileActive : _active;
        if (due && now >= _retryAt)
        {
            try
            {
                if (active) Block(now);
                else Unblock();
                _active = active;
                _lastError = null;
            }
            catch (Exception ex) // the loop boundary: anything that escapes here would skip the back-off below
            {
                // Wait a minute before trying again: no hammering WFP or rescanning folders every tick during a game.
                _retryAt = now + RefreshWhileActive;
                if (ex.Message != _lastError) _log.Error("Game Mode could not update its blocks", ex);
                _lastError = ex.Message;
            }
        }
        else if (!active && !_active) _lastError = null; // nothing left to retry: don't keep showing an old problem

        return Status = new ControllerStatus(active, _settings.Mode, game, _reconciler.Active.Count, games, _lastError);
    }

    private void ReadLibraries(DateTimeOffset now)
    {
        _steam = _steamPath();
        _libraries = SteamLibraries.FindCommonFolders(_steam, _readFile);
        _librariesReadAt = now;
        _classifier = new GameClassifier(_libraries, _settings.AlwaysGames, _settings.NeverGames);
    }

    private void Block(DateTimeOffset now)
    {
        var protectedPaths = ProtectedPaths.ForThisPc(_steam, _libraries, _appFolder);
        var resolver = new TargetResolver(p => protectedPaths.IsProtected(p) || _classifier.IsGame(p), _expandEnv);
        var wanted = resolver.Resolve(BuiltInCatalog.Enabled(_settings.Catalog), _settings.ExtraBlocks);
        var result = _reconciler.Apply(wanted);
        _resolvedAt = now;

        if (!_active) _log.Info($"Game Mode on: blocking {_reconciler.Active.Count} targets");
        else if (result.Added + result.Removed > 0)
            _log.Info($"Game Mode blocks updated: +{result.Added} -{result.Removed}, {_reconciler.Active.Count} in total");
        foreach (var (target, message) in result.Failures)
            if (_loggedFailures.Add(target.Value)) _log.Warn($"Could not block {target.Value}: {message}");
        foreach (var folder in resolver.CappedFolders)
            if (_loggedFailures.Add("cap:" + folder)) _log.Warn($"Only the first {TargetResolver.FolderLimit} programs under {folder} are blocked");
    }

    private void Unblock()
    {
        _reconciler.Clear();
        _loggedFailures.Clear();
        _log.Info("Game Mode off: all blocks removed");
    }

    public void Dispose()
    {
        try
        {
            _reconciler.Clear();
        }
        catch (WfpException ex)
        {
            _log.Error("Could not remove blocks on exit; closing the session removes them anyway", ex);
        }
        _engine.Dispose();
    }
}
```

```csharp
namespace ConnectionManager.Core.Modes;

[Flags]
public enum HotkeyModifiers : uint { None = 0, Alt = 0x1, Control = 0x2, Shift = 0x4, Win = 0x8 }

/// A global hotkey such as "Ctrl+Alt+G": the modifier flags and virtual-key code that RegisterHotKey expects.
public sealed record Hotkey(HotkeyModifiers Modifiers, uint VirtualKey)
{
    /// Accepts Ctrl/Control, Alt, Shift and Win, then one letter, digit or F1–F24. At least one modifier is required.
    public static bool TryParse(string? text, out Hotkey? hotkey)
    {
        hotkey = null;
        if (string.IsNullOrWhiteSpace(text)) return false;
        var parts = text.Split('+', StringSplitOptions.TrimEntries);
        if (parts.Length < 2 || parts.Any(p => p.Length == 0)) return false;

        var modifiers = HotkeyModifiers.None;
        foreach (var part in parts[..^1])
        {
            var flag = part.ToLowerInvariant() switch
            {
                "ctrl" or "control" => HotkeyModifiers.Control,
                "alt" => HotkeyModifiers.Alt,
                "shift" => HotkeyModifiers.Shift,
                "win" => HotkeyModifiers.Win,
                _ => HotkeyModifiers.None,
            };
            if (flag == HotkeyModifiers.None) return false;
            modifiers |= flag;
        }

        if (KeyCode(parts[^1].ToUpperInvariant()) is not { } key) return false;
        hotkey = new Hotkey(modifiers, key);
        return true;
    }

    private static uint? KeyCode(string key)
    {
        if (key.Length == 1 && key[0] is (>= 'A' and <= 'Z') or (>= '0' and <= '9')) return key[0];
        if (key.Length is 2 or 3 && key[0] == 'F' && int.TryParse(key[1..], out var n) && n is >= 1 and <= 24) return (uint)(0x70 + n - 1);
        return null;
    }
}
```

```csharp
    /// Starts the scheduled task that runs Connection Manager elevated. False when the task does not exist.
    public static bool Run(string taskName)
    {
        // Full path: never pick up a schtasks.exe from the current or app folder.
        var start = new ProcessStartInfo(Path.Combine(Environment.SystemDirectory, "schtasks.exe")) { UseShellExecute = false, CreateNoWindow = true };
        foreach (var arg in new[] { "/Run", "/TN", taskName }) start.ArgumentList.Add(arg);
        using var process = Process.Start(start);
        if (process is null) return false;
        process.WaitForExit(10_000);
        return process.HasExited && process.ExitCode == 0;
    }
```

```csharp
using System.Runtime.InteropServices;
using ConnectionManager.Core.Modes;

namespace ConnectionManager.Tray;

/// A hidden window that receives one global hotkey.
internal sealed class HotkeyWindow : NativeWindow, IDisposable
{
    private const int WmHotkey = 0x0312;
    private const uint ModNoRepeat = 0x4000;
    private const int HotkeyId = 1;
    private bool _registered;

    public HotkeyWindow() => CreateHandle(new CreateParams());

    public event Action? Pressed;

    /// False when the text is invalid or another app already owns that key combination.
    public bool Register(string text)
    {
        Unregister();
        if (!Hotkey.TryParse(text, out var hotkey) || hotkey is null) return false;
        _registered = RegisterHotKey(Handle, HotkeyId, (uint)hotkey.Modifiers | ModNoRepeat, hotkey.VirtualKey);
        return _registered;
    }

    protected override void WndProc(ref Message m)
    {
        if (m.Msg == WmHotkey && m.WParam == HotkeyId) Pressed?.Invoke();
        base.WndProc(ref m);
    }

    public void Dispose()
    {
        Unregister();
        DestroyHandle();
    }

    private void Unregister()
    {
        if (_registered) UnregisterHotKey(Handle, HotkeyId);
        _registered = false;
    }

    [DllImport("user32.dll", SetLastError = true)]
    private static extern bool RegisterHotKey(IntPtr hWnd, int id, uint modifiers, uint vk);

    [DllImport("user32.dll", SetLastError = true)]
    private static extern bool UnregisterHotKey(IntPtr hWnd, int id);
}
```

```csharp
using System.Diagnostics;
using ConnectionManager.Core;
using ConnectionManager.Core.Logging;
using ConnectionManager.Core.Modes;
using ConnectionManager.Core.Processes;
using ConnectionManager.Core.Settings;
using ConnectionManager.Core.Steam;
using ConnectionManager.Core.Wfp;

namespace ConnectionManager.Tray;

/// Owns the tray icon, the hotkey and the 2-second Game Mode loop. Everything runs on the UI thread.
internal sealed class TrayContext : ApplicationContext, ITrayCommands
{
    private readonly ILog _log;
    private readonly string _logFolder;
    private readonly SettingsStore _store;
    private readonly TrayIcons _icons = new();
    private readonly NotifyIcon _tray;
    private readonly HotkeyWindow _hotkey = new();
    private readonly System.Windows.Forms.Timer _timer = new() { Interval = 2000 };
    private readonly GameModeController _controller;
    private AppSettings _settings;
    private ControllerStatus _status = ControllerStatus.Starting;
    private bool _menuDirty = true;

    public TrayContext(ILog log, string dataFolder)
    {
        _log = log;
        _logFolder = Path.Combine(dataFolder, "logs");
        _store = new SettingsStore(Path.Combine(dataFolder, "settings.json"));
        _settings = _store.Load();

        _controller = new GameModeController(new SystemProcessSource(), new WfpEngine(), TimeProvider.System, log,
            SteamLibraries.ReadSteamPath, SteamLibraries.ReadFileOrNull, AppContext.BaseDirectory);
        _controller.ApplySettings(_settings);

        _tray = new NotifyIcon { Icon = _icons.Waiting, Text = "Connection Manager", Visible = true };
        _tray.DoubleClick += (_, _) => SetMode(ModeLogic.Toggle(_settings.Mode));

        _hotkey.Pressed += () => SetMode(ModeLogic.Toggle(_settings.Mode));
        if (!_hotkey.Register(_settings.Hotkey))
            _log.Warn($"Hotkey '{_settings.Hotkey}' is invalid or used by another app; change it in settings.json");

        _timer.Tick += (_, _) => Tick();
        _timer.Start();
        Tick();
        _log.Info("Connection Manager started");
    }

    private void Tick()
    {
        var previous = _status;
        _status = _controller.Tick();

        if (_status.Active != previous.Active) Announce();
        if (_status.Active != previous.Active || _status.BlockedCount != previous.BlockedCount || _status.Error != previous.Error
            || !_status.RunningGames.SequenceEqual(previous.RunningGames, StringComparer.OrdinalIgnoreCase))
            _menuDirty = true;

        _tray.Icon = _settings.Mode == GameModeSetting.Off ? _icons.Off : _status.Active ? _icons.Active : _icons.Waiting;
        var text = StatusText();
        _tray.Text = text.Length > 63 ? text[..63] : text;

        // Never swap the menu while it is open; the next tick does it.
        if (_menuDirty && _tray.ContextMenuStrip?.Visible != true) RebuildMenu();
    }

    private string StatusText()
    {
        if (_status.Error is not null) return "Game Mode problem: see the log";
        if (_settings.Mode == GameModeSetting.Off) return "Game Mode: off";
        if (!_status.Active) return "Game Mode: waiting for a game";
        var how = _settings.Mode == GameModeSetting.On ? "on (manual)"
            : _status.Game.GraceEndsAt is not null ? "ending soon"
            : $"on for {_status.Game.GameName}";
        return $"Game Mode {how}: {_status.BlockedCount} blocked";
    }

    private void Announce()
    {
        if (!_settings.Notifications) return;
        if (_status.Active)
            _tray.ShowBalloonTip(3000, "Game Mode on", $"{_status.BlockedCount} updaters can't use the internet until you stop playing.", ToolTipIcon.Info);
        else
            _tray.ShowBalloonTip(3000, "Game Mode off", "Updaters can use the internet again.", ToolTipIcon.Info);
    }

    private void RebuildMenu()
    {
        _menuDirty = false;
        var old = _tray.ContextMenuStrip;
        _tray.ContextMenuStrip = TrayMenu.Build(_settings, _status, StatusText(), this);
        old?.Dispose();
    }

    public void SetMode(GameModeSetting mode) => ChangeSettings(s => s.Mode = mode);

    public void SetCatalogEntry(string id, bool on) => ChangeSettings(s => s.Catalog[id] = on);

    public void AddProgramBlock()
    {
        using var dialog = new OpenFileDialog { Title = "Block this program during games", Filter = "Programs (*.exe)|*.exe" };
        if (dialog.ShowDialog() == DialogResult.OK) AddBlock(new UserBlock(dialog.FileName, false));
    }

    public void AddFolderBlock()
    {
        using var dialog = new FolderBrowserDialog { Description = "Block every program in this folder during games" };
        if (dialog.ShowDialog() == DialogResult.OK) AddBlock(new UserBlock(dialog.SelectedPath, true));
    }

    public void RemoveBlock(UserBlock block)
    {
        if (Confirm($"Stop blocking {block.Path} during games?")) ChangeSettings(s => s.ExtraBlocks.Remove(block));
    }

    public void AddGame()
    {
        using var dialog = new OpenFileDialog { Title = "Treat this program as a game", Filter = "Programs (*.exe)|*.exe" };
        if (dialog.ShowDialog() != DialogResult.OK) return;
        var path = dialog.FileName;
        ChangeSettings(s =>
        {
            s.NeverGames.RemoveAll(p => string.Equals(p, path, StringComparison.OrdinalIgnoreCase));
            if (!s.AlwaysGames.Contains(path, StringComparer.OrdinalIgnoreCase)) s.AlwaysGames.Add(path);
        });
    }

    public void MarkNotAGame(string path)
    {
        if (!Confirm($"{Path.GetFileName(path)} will no longer turn on Game Mode. Continue?")) return;
        ChangeSettings(s =>
        {
            s.AlwaysGames.RemoveAll(p => string.Equals(p, path, StringComparison.OrdinalIgnoreCase));
            if (!s.NeverGames.Contains(path, StringComparer.OrdinalIgnoreCase)) s.NeverGames.Add(path);
        });
    }

    public void RemoveGame(string path, bool fromAlways)
    {
        if (!Confirm($"Remove {Path.GetFileName(path)} from this list?")) return;
        ChangeSettings(s => (fromAlways ? s.AlwaysGames : s.NeverGames).RemoveAll(p => string.Equals(p, path, StringComparison.OrdinalIgnoreCase)));
    }

    public void OpenLogFolder()
    {
        Directory.CreateDirectory(_logFolder);
        var explorer = Path.Combine(Environment.GetFolderPath(Environment.SpecialFolder.Windows), "explorer.exe");
        Process.Start(new ProcessStartInfo(explorer, _logFolder) { UseShellExecute = true });
    }

    public void Exit() => ExitThread();

    private void AddBlock(UserBlock block)
    {
        if (!_settings.ExtraBlocks.Contains(block)) ChangeSettings(s => s.ExtraBlocks.Add(block));
    }

    private void ChangeSettings(Action<AppSettings> change)
    {
        change(_settings);
        try
        {
            _store.Save(_settings);
        }
        catch (Exception ex) when (ex is IOException or UnauthorizedAccessException)
        {
            _log.Error("Could not save settings", ex);
            MessageBox.Show($"Could not save settings: {ex.Message}", "Connection Manager", MessageBoxButtons.OK, MessageBoxIcon.Warning);
        }
        _controller.ApplySettings(_settings);
        _menuDirty = true;
        Tick();
    }

    private static bool Confirm(string question) =>
        MessageBox.Show(question, "Connection Manager", MessageBoxButtons.YesNo, MessageBoxIcon.Question) == DialogResult.Yes;

    protected override void ExitThreadCore()
    {
        _timer.Stop();
        _tray.Visible = false;
        _hotkey.Dispose();
        _controller.Dispose(); // removes every block and closes the WFP session
        _tray.ContextMenuStrip?.Dispose();
        _tray.Dispose();
        _icons.Dispose();
        _log.Info("Connection Manager stopped");
        base.ExitThreadCore();
    }
}
```

```powershell
$root = Split-Path -Parent $PSScriptRoot
$out = Join-Path $root "artifacts\ConnectionManager"

Remove-Item $out -Recurse -Force -ErrorAction SilentlyContinue
dotnet publish (Join-Path $root "src\ConnectionManager.Tray\ConnectionManager.Tray.csproj") -c Release -r win-x64 --self-contained true `
    -p:Version=$Version -p:DebugType=None -o (Join-Path $out "app")
if ($LASTEXITCODE -ne 0) { throw "dotnet publish failed" }

Copy-Item (Join-Path $root "install\*") $out
Remove-Item $zip -Force -ErrorAction SilentlyContinue
Compress-Archive -Path (Join-Path $out "*") -DestinationPath $zip
Write-Host "Created $zip"
```

```powershell
#Requires -RunAsAdministrator
# Dev-PC smoke test of the real app: force Game Mode on, check its WFP block filters exist,
# kill the app the hard way (like a crash), check the filters are gone. Restores settings.json afterwards.
param([string]$Exe = (Join-Path $PSScriptRoot "..\src\ConnectionManager.Tray\bin\Debug\net10.0-windows\ConnectionManager.exe"))
$ErrorActionPreference = "Stop"
$data = Join-Path $env:ProgramData "ConnectionManager"
$settings = Join-Path $data "settings.json"
$backup = "$settings.smoke-backup"
$dump = Join-Path $env:TEMP "cm-smoke-filters.xml"

function Get-BlockFilterCount {
    netsh wfp show filters file="$dump" | Out-Null
    @(Select-String -Path $dump -Pattern "Connection Manager: block" -SimpleMatch).Count
}

New-Item -ItemType Directory -Force -Path $data | Out-Null
if (Test-Path $settings) { Copy-Item $settings $backup -Force }
Set-Content -Path $settings -Value '{ "mode": "On", "notifications": false }' -Encoding UTF8
try {
    $app = Start-Process -FilePath (Resolve-Path $Exe) -PassThru
    Start-Sleep -Seconds 6
    $during = Get-BlockFilterCount
    Stop-Process -Id $app.Id -Force
    Start-Sleep -Seconds 3
    $after = Get-BlockFilterCount
    "Block filters while running: $during (expect more than 0)"
    "Block filters after a hard kill: $after (expect 0)"
    if ($during -gt 0 -and $after -eq 0) { "SMOKE PASSED" } else { "SMOKE FAILED"; exit 1 }
}
finally {
    if (Test-Path $backup) { Move-Item $backup $settings -Force } else { Remove-Item $settings -Force -ErrorAction SilentlyContinue }
}
```

````markdown
# Connection Manager

Stops background updaters (Google, Edge, Razer, Windows Update, Office, Adobe) from using the internet while you play a Steam game, so they can't spike your ping. Nothing is stopped or frozen; they just can't download until you're done.

This is Phase 1 (Game Mode) of [the design](docs/superpowers/specs/2026-10-08-connection-manager-design.md). Data Saver for your phone hotspot comes in Phase 2.

## Install on the gaming PC

1. On the dev PC, run `powershell -ExecutionPolicy Bypass -File tools\publish.ps1`. It creates `artifacts\ConnectionManager-0.1.0.zip`.
2. Copy the zip to the gaming PC and extract it.
3. Double-click `install.cmd` and approve the admin prompt.
4. A round icon appears in the tray:
   - grey: waiting for a game;
   - green: Game Mode is on;
   - red: Game Mode is turned off.

It starts by itself at every logon, and starting it from the Start menu never asks for admin.

## Use

- **Automatic.** Game Mode turns on when a Steam game starts and off 2 minutes after you quit.
- **Manual.** Double-click the icon or press **Ctrl+Alt+G** to force Game Mode on; do it again to go back to Auto.
- **Right-click menu:**
  - Game Mode: Auto, On or Off;
  - what to block;
  - your games list;
  - the log folder.
- **Not a game?** If the menu lists a running program as a game when it isn't, click it to mark it as not a game.
- **Game not detected?** If your Steam library is reached through a junction or symlink, Windows reports the real folder. Use Games → Add a game and pick the exe from that real folder (where the junction points), not through the junction.
- **Steam setting.** In Steam, go to Settings → Downloads and turn off "Allow downloads during gameplay". Steam itself is never blocked.
- **Never blocked**, even if you add them: Windows, Steam, your games, Discord and anti-cheat.

## Check it works on the gaming PC (10 minutes)

1. Start a Steam game. Within 3 seconds the icon turns green, and hovering shows "Game Mode on for <game>.exe: N blocked".
2. While playing, open an admin PowerShell and run:
   `netsh wfp show filters file=$env:TEMP\f.xml; (Select-String $env:TEMP\f.xml -Pattern "Connection Manager: block").Count`
   The number should be more than 0.
3. Razer: while the game runs, change DPI, check your lighting and try a macro. All should still work.
4. Quit the game. After 2 minutes the icon turns grey, and the command from step 2 prints 0.
5. Right-click → Exit, then run step 2 again: still 0.
6. Right-click → Open log folder: today's log shows "Game Mode on: blocking N targets".

## Uninstall

Double-click `uninstall.cmd`. It keeps your settings; run `uninstall.ps1 -RemoveSettings` to remove those too.
````
